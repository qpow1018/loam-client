# 로스트아크 클리어 골드 조회 설계

## 목표

로스트아크 엔드 콘텐츠의 난이도별 입장 레벨과 관문별 클리어 골드를 조회하는 데스크톱 전용 페이지를 추가한다. 첫 구현은 카제로스 레이드 1막(에기르)의 노말·하드 데이터로 화면과 데이터 구조를 검증한다.

이 단계에서는 레벨대별 최대 골드 콘텐츠 계산, 재료 보상, 더보기 비용, 모바일 화면을 다루지 않는다.

## 라우트와 내비게이션

- 새 라우트는 `/lostark/clear-gold`이다.
- Lost Ark 헤더에서 `전체캐릭터`와 `참고 사이트` 사이에 `클리어 골드` 메뉴를 추가한다.
- `page.tsx`는 서버 컴포넌트로 유지한다.
- 선택 상태를 사용하는 화면은 `ClearGoldClient.tsx`가 담당한다.

## 화면 구조

페이지는 기존 Lost Ark 화면과 같은 최대 `1024px` 폭의 gray 기반 다크 UI와 mint 강조색을 사용한다.

데스크톱에서는 좌우 마스터-상세 구조로 표시한다.

- 왼쪽 목록은 약 `280px` 폭이다.
- 콘텐츠명을 상위 항목으로 두고 그 아래에 난이도를 표시한다.
- 선택된 난이도는 mint 계열 테두리와 배경으로 강조한다.
- 첫 진입 시 첫 콘텐츠의 노말 난이도를 선택한다.
- 오른쪽에는 선택한 난이도의 요약과 관문별 표를 표시한다.
- 선택 가능한 데이터가 없으면 오른쪽에 선택 안내를 표시한다.

검색, 아이템 레벨 필터, 모바일 전환 UI는 첫 구현에서 제외한다.

## 상세 표시

상세 상단에는 다음 값을 각각 표시한다.

- 입장 아이템 레벨
- 일반 골드 합계
- 귀속 골드 합계
- 일반 골드와 귀속 골드를 더한 총 획득 골드

관문별 표의 열은 다음 순서로 고정한다.

1. 관문
2. 일반 골드
3. 귀속 골드
4. 합계

귀속 골드가 없는 경우에도 `0`을 표시한다. 모든 골드 숫자는 천 단위 쉼표를 적용한다. 상세 하단에는 데이터 기준일을 표시한다.

## 데이터 구조와 계산

초기 데이터는 라우트 전용 정적 상수로 관리한다. 각 콘텐츠는 난이도 목록을 가지며 각 난이도에는 다음 값을 저장한다.

- 고유 식별자
- 표시 이름
- 입장 아이템 레벨
- 데이터 기준일
- 관문 목록
- 관문별 일반 골드
- 관문별 귀속 골드

일반 골드 합계, 귀속 골드 합계, 총 획득 골드는 상수로 중복 저장하지 않는다. 관문 데이터를 합산하는 순수 함수로 계산해 보상 수정 시 합계가 어긋나지 않게 한다.

라우트 전용 파일은 기존 프로젝트 규칙에 따라 `_type`, `_define`, `_component`에 배치한다. 두 번째 기능인 레벨대별 최대 골드 계산에서 같은 데이터가 실제로 필요해질 때만 공용 Lost Ark 도메인으로 이동한다.

## 초기 데이터

데이터 기준일은 `2026.03.15`이다.

### 카제로스 레이드 1막: 에기르 노말

- 입장 아이템 레벨: 1660
- 1관문: 일반 골드 3,500 / 귀속 골드 0 / 합계 3,500
- 2관문: 일반 골드 8,000 / 귀속 골드 0 / 합계 8,000
- 전체: 일반 골드 11,500 / 귀속 골드 0 / 총 획득 골드 11,500

### 카제로스 레이드 1막: 에기르 하드

- 입장 아이템 레벨: 1680
- 1관문: 일반 골드 5,500 / 귀속 골드 0 / 합계 5,500
- 2관문: 일반 골드 12,500 / 귀속 골드 0 / 합계 12,500
- 전체: 일반 골드 18,000 / 귀속 골드 0 / 총 획득 골드 18,000

초기 수치는 2026년 3월 15일 갱신된 보상 정리와 별도 골드 보상표를 교차 확인한 값이다. 이후 패치로 값이 바뀌면 관문별 정적 데이터와 기준일을 함께 수정한다.

## 오류와 빈 상태

정적 데이터만 사용하므로 로딩 상태와 네트워크 오류 상태는 만들지 않는다. 콘텐츠 또는 난이도 배열이 비어 있어 선택값을 만들 수 없는 경우에만 상세 영역에 안내 문구를 표시한다.

## 검증

- `npm run lint`로 TypeScript, React, SCSS 변경을 확인한다.
- 데스크톱 브라우저에서 `/lostark/clear-gold`를 열어 목록 선택, 상세 갱신, 합계, 천 단위 표기, 1024px 레이아웃을 확인한다.
- 헤더와 새 라우트가 production build에서 정상 동작하는지 `npm run build:webpack`으로 확인한다.

## 완료 기준

- Lost Ark 헤더에서 클리어 골드 페이지로 이동할 수 있다.
- 에기르 노말과 하드를 왼쪽 계층형 목록에서 선택할 수 있다.
- 선택한 난이도의 입장 레벨, 관문별 일반·귀속·합계 골드, 전체 합계를 오른쪽에서 확인할 수 있다.
- 관문별 값 변경만으로 모든 합계가 자동 갱신된다.
- 데이터 기준일이 화면에 표시된다.
- 첫 범위에서 제외한 최대 골드 계산, 재료, 더보기 비용, 검색·필터, 모바일 UI가 포함되지 않는다.
