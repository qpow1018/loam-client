# 로스트아크 클리어 골드 데이터 확장 설계

## 목표

기존 `/lostark/clear-gold` 페이지에 그림자 레이드, 지평의 성당, 카제로스 레이드의 관문별 일반·귀속 골드를 추가한다. 화면의 마스터-상세 구조는 유지하고 왼쪽 목록에 카테고리 계층만 추가한다.

## 범위

포함하는 카테고리와 콘텐츠는 다음과 같다.

1. 그림자 레이드
   - 죽음의 계율자, 벨가르딘
   - 고통의 마녀, 세르카
2. 어비스 던전
   - 지평의 성당
3. 카제로스 레이드
   - 종막 최후의 날
   - 4막 파멸의 성채
   - 3막 칠흑, 폭풍의 밤
   - 2막 아브렐슈드
   - 1막 에기르
   - 서막 에키드나

기간 한정 EX 콘텐츠, 재료 보상, 더보기 보상과 비용, 검색, 필터, 모바일 UI는 포함하지 않는다.

## 데이터 출처와 기준

- 출처: `https://www.daloa.xyz/clear`
- 데이터 기준일: `2026.06.24`
- 다로아 화면에 표시된 관문별 입장 레벨과 `[일반]`, `[귀속]` 값을 정적 데이터로 옮긴다.
- 런타임에 다로아를 호출하거나 데이터를 자동 수집하지 않는다.
- 출처의 값이 바뀌면 정적 관문 데이터와 기준일을 함께 수정한다.

## 데이터 구조

기존 `콘텐츠 → 난이도 → 관문` 구조 위에 카테고리를 추가해 다음 계층으로 관리한다.

`카테고리 → 콘텐츠 → 난이도 → 관문`

새 카테고리 타입은 고유 식별자, 표시 이름, 콘텐츠 배열을 가진다. 콘텐츠·난이도·관문 타입과 합산 함수는 기존 구조를 유지한다. 정적 상수는 카테고리 배열을 기준으로 저장하고, 선택된 난이도를 찾을 때만 카테고리와 콘텐츠를 순회한다.

## 정렬 규칙

카테고리 순서는 다음으로 고정한다.

1. 그림자 레이드
2. 어비스 던전
3. 카제로스 레이드

각 카테고리 안의 콘텐츠와 각 콘텐츠 안의 난이도는 입장 레벨이 높은 항목부터 표시한다.

- 그림자 레이드: 벨가르딘 → 세르카
- 어비스 던전: 지평의 성당
- 카제로스 레이드: 종막 → 4막 → 3막 → 2막 → 1막 → 서막
- 일반 난이도 순서: 나이트메어 → 하드 → 노말 → 싱글
- 지평의 성당: 3단계 → 2단계 → 1단계

3막, 2막, 1막, 서막의 싱글은 다로아 기준으로 노말과 입장 레벨 및 모든 관문별 일반·귀속 골드가 같다. 중복을 피하기 위해 싱글은 저장하거나 표시하지 않는다.

## 초기 선택과 화면

- 첫 진입 시 첫 카테고리의 첫 콘텐츠와 첫 난이도인 `벨가르딘 나이트메어`를 선택한다.
- 왼쪽 목록은 카테고리 제목 아래에 기존 콘텐츠명과 난이도 버튼을 표시한다.
- 오른쪽 상세의 입장 레벨, 일반 골드, 귀속 골드, 총 획득 골드, 관문별 표, 데이터 기준일 표시는 변경하지 않는다.
- 카테고리 또는 데이터가 비어 있으면 기존 선택 안내를 표시한다.

## 테스트와 검증

- 카테고리 순서와 각 카테고리의 콘텐츠 순서를 테스트한다.
- 각 콘텐츠의 난이도 순서, 입장 레벨, 기준일, 관문별 일반·귀속 골드를 테스트한다.
- 기존 합산 함수 테스트로 일반·귀속·전체 합계가 관문 데이터에서 파생되는지 확인한다.
- 노말과 동일한 싱글 난이도가 정적 데이터에 포함되지 않았는지 확인한다.
- 변경 파일에 targeted Prettier를 실행한다.
- `npm run lint`와 `npm run build:webpack`을 실행한다.
- 가능하면 데스크톱 브라우저에서 카테고리 제목, 기본 선택, 난이도 전환과 상세 합계를 확인한다.

## 완료 기준

- 왼쪽 목록이 `그림자 레이드 → 어비스 던전 → 카제로스 레이드` 순서로 표시된다.
- 카테고리 내부 콘텐츠와 난이도가 승인된 고레벨 우선 순서로 표시된다.
- 벨가르딘, 세르카, 지평의 성당, 종막, 4막, 3막, 2막, 1막, 서막의 관문별 일반·귀속 골드를 조회할 수 있다.
- 노말과 값이 같은 싱글 난이도는 표시되지 않는다.
- 첫 진입 시 벨가르딘 나이트메어가 선택된다.
- 기존 에기르 데이터가 다로아 기준 일반·귀속 분할로 교체된다.
- 더보기 골드나 범위 밖 콘텐츠가 추가되지 않는다.
