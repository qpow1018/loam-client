# 로스트아크 일반 재련 최적화 조사

> 조사 기준일: 2026-07-22 KST  
> 조사 대상: 에기르·세르카 일반 재련  
> 목적: LoaM 재련 최적화 기능에서 사용할 고정 게임 규칙과 외부 계산기의 신뢰 범위를 정리한다.

## 결론

외부 계산기의 화면이나 데이터를 개발 시점의 참고 자료로 가져오는 것은 가능하지만, 특정 사이트의 값을 실행 시점에 그대로 스크래핑하거나 계산 결과를 정답으로 사용하면 안 된다.

이번 조사에서 고정 데이터 오류, 최신 패치 미반영, 기대 시도 계산 오류가 실제로 발견됐다. LoaM은 고정 재련 규칙을 직접 소유하고, 공식 패치와 복수의 외부 자료를 통해 변경 여부를 검증해야 한다.

장비 성장은 완료되어야 재련을 시작할 수 있는 선행 조건이므로 재련 최적화 범위에서 제외하며, 성장에 사용된 파편과 실링은 재련 비용에 포함하지 않는다.

현재 기준으로 권장하는 검증 우선순위는 다음과 같다.

1. 로스트아크 공식 업데이트 공지
2. 현재 인게임 재련 화면에서 직접 확인한 값
3. Loatto와 아이스펭의 현재 적용값 및 계산 규칙
4. GCalc는 보조 참고 자료로만 사용

## 확정된 일반 재련 규칙

### 기본 성공률

아래 단계는 재련 후 도달하는 목표 단계를 의미한다.

| 목표 단계 | 에기르 | 세르카 실사용 구간 |
| --------- | -----: | -----------------: |
| +11       |    10% |                  - |
| +12       |    10% |                 5% |
| +13       |     5% |                 5% |
| +14       |     5% |                 4% |
| +15       |     4% |                 4% |
| +16       |     4% |                 4% |
| +17~+19   |     3% |                 3% |
| +20~+21   |   1.5% |               1.5% |
| +22~+23   |     1% |                 1% |
| +24~+25   |   0.5% |               0.5% |

### 실패 누적 성공률

실패할 때마다 다음 시도의 기본 성공률은 최초 기본 성공률의 10%만큼 증가한다.

```text
다음 시도 기본 성공률
= 최초 기본 성공률 + 최초 기본 성공률 × 0.1 × 실패 횟수

누적 성공률 상한
= 최초 기본 성공률 × 2
```

기본 성공률이 4%인 경우의 무보조 성공률은 다음과 같다.

```text
1회: 4.0%
2회: 4.4%
3회: 4.8%
...
11회 이후: 8.0%
```

4%에 10%p를 더하는 것이 아니라, 4%의 10%인 0.4%p씩 증가한다.

### 장인의 기운

재련에 실패하면 해당 시도의 실제 성공률을 기준으로 장인의 기운이 증가한다.

```text
실패 시 장인의 기운 증가
= 해당 시도의 실제 성공률 ÷ 2.15
```

실제 성공률에는 실패 누적 성공률, 숨결, 책과 이벤트 성공률 보너스가 포함된다.

기본 성공률 4%인 첫 시도에 보조 재료를 사용하지 않고 실패했다면 다음과 같다.

```text
4 ÷ 2.15 = 1.860465...%
```

실패 후 장인의 기운이 100% 이상이 되면 다음 시도는 확정 성공한다. 확정 성공 시도에는 숨결과 책을 사용하지 않는다.

아이스펭의 공개 구현에서도 같은 공식을 확인할 수 있다.

- [아이스펭 재련 계산 코드](https://github.com/icepeng/loa-calc/blob/4a731f4c080ceb7ee19bf2aa324ddce6072ef2f4/src/app/refining/refine.ts)
- [아이스펭 재련 고정 데이터](https://github.com/icepeng/loa-calc/blob/4a731f4c080ceb7ee19bf2aa324ddce6072ef2f4/src/app/refining/data.ts)

### 숨결

| 기본 성공률 |  최대 수량 |           1개 효과 | 최대 추가 성공률 |
| ----------: | ---------: | -----------------: | ---------------: |
|         10% |         20 |              0.5%p |             10%p |
|          5% |         20 |             0.25%p |              5%p |
|          4% |         20 |              0.2%p |              4%p |
|          3% | 20 또는 25 | 0.15%p 또는 0.12%p |              3%p |
|        1.5% |         25 |             0.06%p |            1.5%p |
|          1% |         25 |             0.04%p |              1%p |
|        0.5% |         50 |             0.02%p |              1%p |

3% 구간은 장비군에 따라 최대 수량과 개당 효과가 다르다.

- 에기르: 20개 × 0.15%p
- 세르카: 25개 × 0.12%p

  0.5% 구간은 최대 숨결의 추가 성공률이 0.5%p가 아니라 1%p라는 점을 주의한다.

### 책

에기르 장비는 다음 단계에서 야금술 또는 재봉술 책을 사용할 수 있다.

| 목표 단계 | 책             |
| --------- | -------------- |
| +11~+14   | 업화 `[11-14]` |
| +15~+18   | 업화 `[15-18]` |
| +19~+20   | 업화 `[19-20]` |
| +21 이상  | 없음           |

세르카 장비에는 사용할 수 있는 책이 없다.

일반 책은 해당 단계의 최초 기본 성공률만큼 성공률을 추가한다. 강화형 `[19-20]`처럼 효과가 다른 아이템은 같은 책으로 합치지 않고 별도 아이템과 별도 효과로 모델링한다.

| --------------------- | -------------: | -------------: |
| 에기르 무기 +10→+11   |         1,620G |         1,296G |

### 세르카 무기 +15→+16 돌파석

위대한 운명의 돌파석은 25개가 맞다.

```text
운명의 파괴석 결정: 2,460
위대한 운명의 돌파석: 25
상급 아비도스 융화 재료: 27
운명의 파편: 22,960
```

아이스펭과 Loatto가 25개로 일치한다.

GCalc만 35개를 사용하고 있어 GCalc의 고정 데이터 오류로 판정한다.

## 외부 계산기에서 발견한 계산 오류

### LoaUp: 첫 시도 off-by-one

LoaUp은 기대비용 계산을 실패 횟수 0이 아니라 1에서 시작한다. 이로 인해 첫 시도부터 실패 1회의 성공률 증가를 적용한다.

| 항목                      |        정상 |       LoaUp |
| ------------------------- | ----------: | ----------: |
| 기본 4% 첫 시도 성공률    |          4% |        4.4% |
| 첫 실패 장인의 기운       |    약 1.86% |    약 2.05% |
| 기본 10% 무보조 기대 시도 |  약 6.638회 |  약 6.264회 |
| 기본 4% 무보조 기대 시도  | 약 13.700회 | 약 13.328회 |

이 오류로 평균비용과 장인 100% 비용이 실제보다 작게 계산될 수 있다. LoaUp의 재료 테이블은 참고할 수 있지만 기대비용, 장인 100%, 최적 전략 결과는 정답으로 사용하지 않는다.

### GCalc: 실링 중복 계산과 제한된 최적화 탐색

GCalc는 실링을 기본 재료 목록에서 한 번 계산하고 별도 `silverCost`로 다시 더한다. 따라서 실링의 골드 환산 가치가 총 비용에 두 번 포함된다.

또한 보조 재료 사용 시점을 0~25회까지만 열거한 다음 전부 사용하는 전략으로 넘어간다. 장인 100%까지 25회를 넘는 +21~+25 저확률 구간에서는 가격에 따라 최적일 수 있는 중간 사용 전략을 놓칠 수 있다.

## LoaM 구현 원칙

### 외부 사이트를 런타임 원본으로 사용하지 않는다

외부 사이트의 HTML이나 번들을 사용자 요청마다 스크래핑하지 않는다.

- 사이트 구조 변경이 LoaM 장애로 이어질 수 있다.
- 외부 사이트가 잘못된 데이터를 배포하면 LoaM도 동시에 틀리게 된다.
- 과거 패치의 원본 비용과 현재 적용 비용을 구분하기 어렵다.
- 시세 기준이 `RecentPrice`, 전일 평균가, 최저가 등으로 서로 다르다.

외부 사이트는 고정 데이터 변경을 감지하거나 개발 중 교차검증하는 자료로만 사용한다.

### 고정 규칙과 변동 입력을 분리한다

```text
고정 재련 규칙
├─ 장비군과 부위
├─ 목표 단계
├─ 최초 기본 성공률
├─ 실패 누적 규칙
├─ 장인의 기운 공식
├─ 시도당 필수 재료
├─ 현재 적용 시도 골드
└─ 숨결·책의 수량과 확률 효과

기간 정책
├─ 익스프레스 성공률 보너스
├─ 재료·파편·실링 감소
├─ 적용 장비군과 단계
└─ 적용 시작일과 종료일

변동 입력
├─ 거래소 시세
├─ 귀속 재료 가치
├─ 사용자가 보유한 재료
└─ 현재 실패 누적과 장인의 기운
```

고정 규칙은 현재 게임에 적용되는 값을 직접 소유한다. 에기르 +11~+18 시도 골드는 공식 20% 감소가 적용된 현재값을 사용하며, 패치 전 원본값은 검증 이력으로만 문서에 남긴다. 기간에 따라 달라지는 익스프레스·이벤트 보너스는 고정 데이터에 합치지 않는다.

### 순수 계산 엔진을 둔다

계산 엔진은 UI와 시세 조회에서 분리한다.
현재 기능은 사용자가 선택한 현재 단계에서 다음 단계까지 한 번 성공하는 비용만 계산한다. 별도 목표 단계 입력과 여러 단계 연속 합산은 제공하지 않는다.

입력 예시:

```text
- 장비군과 부위
- 현재 단계
- 현재 실패 누적 횟수
- 현재 장인의 기운
- 보유 재료와 재료별 평가 가격
```

보유 재료는 기본 0골드로 평가하고, 보유량을 초과하는 부족분만 시세로 구매한 것으로 계산한다. 사용자가 재료별 가격 0G 처리를 선택하면 보유 수량과 관계없이 해당 재료 비용 전체를 제외한다.

출력 예시:

```text
- 시도별 권장 숨결·책 수량
- 시도별 성공률과 장인의 기운
- 기대 시도 횟수
- 기대 재료 수량
- 기대 비용 (실링 제외)
- 기대 실링
- 장인 100% 비용 (실링 제외)
- 장인 100%까지 실링
```

동일한 입력에는 항상 동일한 결과가 나와야 하며, 시장 시세 조회나 화면 반올림이 계산 엔진 내부에 들어가면 안 된다.
실링은 골드로 환산하지 않고 기대치와 장인 100% 기준치를 별도로 표시하므로 골드 최적화 목적함수에 포함하지 않는다.

## 필수 회귀 테스트

최소한 다음 고정값과 계산 경계를 자동 테스트한다.

### 규칙 테스트

- 에기르 +14→+15 무보조 첫 시도는 4%다.
- 첫 실패 후 다음 시도는 4.4%다.
- 첫 실패 장인의 기운은 `4 / 2.15`, 약 1.860465%다.
- 실패 누적 성공률은 최초 기본 성공률의 두 배를 넘지 않는다.
- 장인의 기운 100% 확정 시도에는 숨결과 책을 사용하지 않는다.
- 확정 성공 시도는 기대 시도 계산에 정확히 한 번만 포함된다.

### 고정 데이터 테스트

- 에기르 무기 +10→+11 현재 적용 골드는 1,296G다.
- 에기르 방어구 +10→+11 현재 적용 골드는 776G다.
- 세르카 무기 +15→+16 위대한 운명의 돌파석은 25개다.
- 세르카 무기 +18→+19 시도당 파편은 29,040개다.

### 기대값 테스트

- 기본 10% 무보조, 장인의 기운 0%의 기대 시도는 약 6.638회다.
- 기본 4% 무보조, 장인의 기운 0%의 기대 시도는 약 13.700회다.
- 기대 시도와 장인 100% 시도는 LoaUp의 off-by-one 결과를 재현하지 않는다.
- 기대 실링은 `시도당 실링 × 기대 시도`로 별도 계산되며 골드 비용에 포함되지 않는다.
- 장인 100%까지 실링은 `시도당 실링 × 최대 시도`로 별도 계산된다.
- 저확률 구간에서도 장인 100%까지 가능한 전체 전략을 비교한다.

## 데이터 갱신 절차

로스트아크 성장 완화나 신규 장비가 추가되면 다음 순서로 갱신한다.

1. 공식 업데이트 공지에서 적용 대상, 단계, 감소율과 적용일을 확인한다.
2. 현재 인게임 재련 화면이나 신뢰 가능한 최신 화면에서 대표 단계를 확인한다.
3. Loatto와 아이스펭의 현재 적용값을 비교한다.
4. GCalc로 전체 단계 테이블을 보조 비교한다.
5. 불일치가 있으면 다수결로 결정하지 않고 공식 공지 또는 인게임 값으로 판정한다.
6. 고정 데이터 버전과 근거 URL을 함께 갱신한다.
7. 회귀 테스트를 먼저 수정한 다음 계산 결과를 검증한다.
