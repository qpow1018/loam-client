# 로스트아크 일반 재련 고정 규칙

> 기준일: 2026-07-22 KST  
> 범위: 에기르·세르카 장비 일반 재련  
> 용도: 구현 전 사람 검수용 기준 문서. 시장 시세, 보유 재료, 이벤트 가격은 포함하지 않는다.

## 1. 검수 상태

| 상태          | 의미                                                                              |
| ------------- | --------------------------------------------------------------------------------- |
| `공식 확정`   | 로스트아크 공식 업데이트 공지로 적용 범위 또는 변경값을 확인했다.                 |
| `인게임 확인` | 실제 게임의 재련 화면에서 값을 직접 확인했다.                                     |
| `교차검증`    | 서로 독립적인 복수 계산기의 현재 UI·공개 데이터에서 같은 값을 확인했다.           |
| `확인 필요`   | 사이트 간 값이 다르거나 공식 수치표를 찾지 못해 인게임 대표 단계 확인이 필요하다. |

이 문서의 표는 현재 가장 신뢰도가 높은 값으로 정리했지만, `교차검증` 값은 기능 배포 전에 인게임 재련 화면의 대표 단계와 한 번 더 대조한다.

## 2. 범위와 표기

- `현재 +10 → 목표 +11`은 표에서 `+10→+11`로 표기한다.
- 시도 비용은 재련 버튼을 한 번 누를 때마다 반복해서 소모되는 값이다.
- 장비 성장은 완료되어야 재련을 시작할 수 있는 선행 조건이며 재련 최적화 범위에서 제외한다.
- 장비 성장에 사용된 파편과 실링은 재련 비용·기대값·장인 100% 비용에 포함하지 않는다.
- 에기르 +11~+18 골드는 2025-12-10 성장 지원 20% 감소가 적용된 현재값을 사용한다.
- 에기르 골드는 인게임에서 방어구 +10→+11 `776`, 방어구 +11→+12 `856`, 무기 +11→+12 `1,432`를 직접 확인했다.
- 순환 돌파석·계승 돌파석 등 특수 재련 재료는 일반 재련 필수 재료가 아니므로 이 문서의 핵심 시도 비용 표에서 제외한다.

## 3. 변하지 않는 계산 공식

이 절은 이벤트가 적용되지 않은 일반 재련의 기본 계산 구조를 정의한다. 익스프레스·이벤트처럼 기간에 따라 달라지는 보너스는 고정 단계 데이터에 합치지 않고 별도 정책 입력으로 적용한다.

| 계산 규칙             | 검수 상태       | 검증 결과                                     |
| --------------------- | --------------- | --------------------------------------------- |
| 실패 누적 성공률      | `교차검증`      | 아이스펭·Loatto·GCalc가 같은 공식을 사용한다. |
| 실제 시도 성공률      | `교차검증`      | 기본률·책·숨결·정책 보너스를 합산한다.        |
| 장인의 기운 증가      | `교차검증 채택` | 세 사이트 모두 실제 성공률을 `2.15`로 나눈다. |
| 장인의 기운 확정 성공 | `교차검증`      | 100% 도달 후 다음 시도가 확정 성공한다.       |

장인의 기운 `÷ 2.15`는 세 사이트가 일치한 현재 구현 기준이다. 공식 수치표는 확인하지 못했으므로 인게임 판별 확인 항목은 별도로 유지한다.

### 3.1 실패 누적 성공률

```text
현재 기본 성공률
= min(최초 기본 성공률 × (1 + 실패 횟수 × 0.1), 최초 기본 성공률 × 2)
```

- 첫 시도에는 실패 보정을 적용하지 않는다.
- 실패 1회마다 최초 기본 성공률의 10%만큼 증가한다.
- 실패 누적 기본 성공률은 최초 기본 성공률의 2배를 넘지 않는다.
- 여기서 실패 횟수는 현재 시도 전에 누적된 실패 횟수다.

기본 성공률 4%의 무보조 예시:

```text
1회 4.0% → 2회 4.4% → 3회 4.8% → ... → 상한 8.0%
```

### 3.2 실제 시도 성공률

```text
실제 시도 성공률
= min(현재 기본 성공률 + 책 보너스 + 숨결 보너스 + 적용 중인 정책 보너스, 100%)
```

- 책·숨결·정책 보너스는 `%p` 단위로 현재 기본 성공률에 더한다.
- 이벤트가 없는 일반 재련에서는 정책 보너스를 `0`으로 입력한다.
- 익스프레스·이벤트 성공률 보너스는 이 문서의 단계별 기본값에 합치지 않는다.

### 3.3 장인의 기운

```text
실패 후 장인의 기운
= 실패 전 장인의 기운 + 실제 시도 성공률 ÷ 2.15
```

- 첫 시도 전 장인의 기운 기본값은 0%다.
- 장인의 기운은 재련에 실패했을 때만 증가한다.
- 실제 시도 성공률에는 실패 누적, 책, 숨결과 적용 중인 정책 보너스가 모두 포함된다.
- 내부 계산값은 반올림하지 않고 누적하며, 화면 표시용 반올림은 계산과 분리한다.

기본 성공률 4% 첫 시도에 보조 재료를 사용하지 않고 실패한 경우:

```text
4 ÷ 2.15 = 1.860465...%
```

인게임 판별 예시:

```text
최초 기본 성공률 3%, 선택 재료 없음, 장인의 기운 0%에서 시작
첫 실패: 3.0% ÷ 2.15
두 번째 실패: 3.3% ÷ 2.15
두 번 실패 후 누적 장인의 기운: 2.930232...%
```

### 3.4 장인의 기운 확정 성공

```text
실패 후 장인의 기운 ≥ 100%
→ 다음 시도 성공률 100%
```

- 확정 성공 시도에는 책과 숨결을 사용하지 않는다.
- 확정 성공 시도에도 필수 시도 재료는 정확히 한 번 소모한다.
- 확정 성공 시도는 기대 시도 횟수와 기대 재료량에 정확히 한 번 포함한다.
