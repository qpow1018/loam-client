## 섹션 분류

### 캐릭터 세팅 상세

1. **프로필 요약**
   - 캐릭터 이미지, 서버·직업, 아이템 레벨, 전투력
   - 캐릭터/원정대 레벨, 길드·영지, 순위
2. **장비**
   - 무기·방어구의 강화, 품질, 아이템 레벨
   - 초월·진화 등 성장 정보
3. **장신구·특수 장비**
   - 목걸이·귀걸이·반지의 기본/연마 효과
   - 어빌리티 스톤, 팔찌, 엘릭서·보주 등 개별 효과
4. **보석**
   - 보석 레벨·종류·연결 스킬·효과
   - 멸화/홍염 분포와 평균 레벨
5. **아크 패시브**
   - 진화·깨달음·도약 포인트
   - 선택한 노드와 효과
6. **아크 그리드**
   - 코어 구성, 포인트, 활성 효과
   - 보스 피해 등 핵심 결과값
7. **각인·전투 정보**
   - 각인 레벨과 어빌리티 스톤 보너스
   - 공격력·최대 생명력·치명/특화 등 전투 특성
8. **카드**
   - 장착 카드, 세트 효과, 각성 단계
9. **스킬**
   - 스킬트리, 룬, 트라이포드, 스킬 포인트
   - 카운터·무력화 같은 전투 지표
10. **아바타**
    - 장착 아바타와 세트/전설 아바타 정보

## 현재 데이터 지원 범위

현재 `TResLostarkCharacterSummary`로 바로 구성할 수 있는 범위는 다음과 같다.

- 프로필 요약 일부: 이미지, 서버, 직업, 아이템 레벨, 전투력
- 장비: 무기·방어구의 강화, 품질, 아이템 레벨
- 장신구: 악세서리, 어빌리티 스톤, 팔찌
- 각인, 보석, 아크 패시브, 아크 그리드, 전설 아바타

카드, 스킬, 상세 전투 특성, 엘릭서·보주·초월 등의 별도 표기는
현재 요약 타입에 없으므로 데이터 계약을 확장한 뒤 추가한다.

## 다음 논의 대상

현재 데이터로 가능한 핵심 섹션의 우선순위와 화면 배치를 정한다.

## 테스트 환경 정리 체크리스트

상세 화면 개발이 완료되면 다음 항목을 함께 정리한다.

- 테스트 테이블을 제거하는 후속 migration 추가
- 테스트 테이블 전용 API와 타입 제거
- 테스트 갱신·저장 UI 제거
- 최종 화면을 운영 메인 캐릭터 API에 연결
- 테스트 데이터와 테스트 전용 코드가 남아 있지 않은지 확인
